# Arin-Rae-Art Data Cleaning & Transformations

## This package includes:
- main.py
- transforms.py

## This package requires:
- Python 3+
- Pandas
- DuckDb

## Command Syntax
python3 main. py <sales_filename> (required) <inventory_filename> (optional)

## Outputs (Default File Names)
- transformed_sales.csv (from sales_filename)
- transformed_inventory.csv (from inventory_filename)
